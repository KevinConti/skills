# Brief — `handoff` *(inline)*

Invoke `handoff` with the focus "implement \<item\>". This produces the implementation primer.

Critically: ensure the handoff doc captures **every risk and open item plan-review surfaced**, plus links to the plan, `CONTEXT.md`, ADRs, and the relevant code. These must reach implementation — the handoff is the only thing the sub-agent will see. **Capture the handoff doc's path**; it becomes the implementation sub-agent's brief.
