# Shape the interface — `impeccable shape` ⛔ *(inline — interactive)*

Invoke **`impeccable shape`** with the feature, handing it the realism floor as context. It runs a discovery interview — the user answers live — and produces a confirmed **design brief** (Primary User Action, Layout Strategy, Key States, Interaction Model, Content Requirements, …). This step is **inline**: it's live human collaboration, so it can't be delegated. UI leads — design for the best UX within the floor, not around a premature contract.

This is **`shape`, not `craft`** — design planning only, no code; it ends at its own confirmation gate. ⛔ that confirmation is the gate. (If `impeccable` reports missing `PRODUCT.md`/`DESIGN.md` context, let it run its `teach`/`document` setup first.) The brief's Content Requirements / Key States / Interaction Model are the input to the contract step.
